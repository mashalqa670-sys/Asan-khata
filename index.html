Cloud synchronisation setup

For genuine multi-device sync, create one free Supabase project, run the included SQL schema, then paste the project URL and anon key here. Use the same setup on every device. The app does not send data to a server until you configure this.

Transaction manager access

Only the designated manager should enter contributions and expenses. Set a manager PIN, then unlock transaction entry on the manager’s device. This starter PIN is a convenience lock, not strong server-side security; enforceable roles require authenticated accounts and database policies.

Never paste a service-role key here. The included SQL enables shared room data access for anyone with the app's project credentials; only share the app with your six roommates.

Important setup steps

  1. Create a project at Supabase.
  2. Open SQL Editor and run schema.sql from the downloaded project.
  3. Copy the Project URL and anon/publishable key from Project Settings → API.
  4. Paste both above on one device, connect, then use the same URL/key on all other devices.
  5. Deploy this folder to a static host (for example, Netlify or Vercel) so all phones and PCs can open the same app address.
